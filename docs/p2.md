// Sized and shaped to match `previewDiagramLayout` (wwell-ir-preview-diagram-layout.ts)
// exactly — `780 / 650`, not the old default layout's `1040 / 840` — so the SVG's own viewBox
// aspect ratio equals this box's CSS aspect ratio 1:1. With `preserveAspectRatio="none"` (see
// well-bore-view.component.ts / wwell-ir-depth-scale.component.ts) any mismatch between the two
// stretches the drawing non-uniformly; matching them keeps it undistorted at any box size.
// `max-height: 500px` deliberately isn't a headroom guess: at this exact 780:650 ratio it's what
// lets `max-width: 600px` bind too (500 × 780/650 = 600) — the box uses its full available width
// instead of being height-capped down to ~420px the way the old 340px max-height forced it to be.
// A bigger box is what actually fixes the diagram's small text/tooltips: everything here (labels,
// tooltips, casing widths, spacing) is drawn in fixed viewBox units and scales *together* off of
// `containerPx / wellboreViewWidth` — so growing the container is the one lever that reliably
// grows all of it at once, in proportion, with zero risk of a label overlapping its neighbor (the
// spacing around it grew by the exact same factor). Deliberately NOT layering a further font-size
// bump on top of this in CSS: a bump changes only the text, not the fixed-viewBox-unit spacing
// around it (leader-line offsets, tooltip row heights, tick spacing), so it re-introduces the
// exact overlap this proportional box-resize was meant to avoid — confirmed live, see git history
