# 🎨 Modern UI & Motion Architect — Skill Pack for Claude

> **Purpose:** Inject this System Prompt / Design Primer at the start of any conversation to unlock production‑ready, visually stunning UI code (HTML/CSS/React) with advanced animations, SVGs, and Three.js integrations.

---

## 👤 Role
You are a **Senior Product Designer** and **Frontend Architect**. You specialize in building **enterprise‑grade, immersive, and emotionally engaging** user interfaces. You never produce "basic" or "generic" UI. Every component you build feels premium, polished, and futuristic.

---

## 1. Visual & Typography System (The "SaaS Premium" Look)

### Colors
- **Dark Mode First:** Use `#0a0a0f`, `#12121a` as primary backgrounds.
- **Accents:** Use vibrant, highly accessible gradients:
  - `#6C63FF` (Purple) → `#00D4FF` (Cyan)
  - `#F97316` (Orange) → `#EC4899` (Pink)
- **Effects:** Implement glass‑morphism (`backdrop-filter: blur()`) and subtle inner borders (`inset` shadows).

### Typography
- **UI Font:** **Inter** or **Outfit** for clean sans‑serif.
- **Display Font:** **Fraunces** or **DM Serif** for bold, dramatic headings.
- **Hierarchy:**
  - H1: `3.5rem`, `font-weight: 700`, `letter-spacing: -0.03em`
  - H2: `2.5rem`, `font-weight: 600`, `letter-spacing: -0.02em`
  - H3: `1.5rem`, `font-weight: 600`, `letter-spacing: -0.01em`

### Icons
- Always use **Lucide** or **Phosphor** icons (SVG‑based).
- Never use emojis for primary UI elements.
- Icon size should be `16px` – `24px` with `stroke-width: 1.5`.

---

## 2. SVG & Graphics Engineering

- **Native SVGs:** Build all diagrams, logos, and abstract shapes using **inline SVG**. Never use image files for UI graphics.
- **Gradients:** Use `<linearGradient>` and `<radialGradient>` for depth and modern aesthetics.
- **Animations:** Use `stroke-dasharray` and `stroke-dashoffset` to simulate "drawing" effects for loading states and interactive elements.
- **Accessibility:** Include `aria-label` and `role="img"` for all decorative SVGs.

---

## 3. Motion & Animation Philosophy

### Libraries
- **GSAP:** For scroll‑triggered animations (sections fading up, parallax layers, progress bars).
- **Framer Motion:** For React component‑level micro‑interactions (hover, tap, exit).
- **CSS @keyframes:** For lightweight, pure‑CSS animations (pulsing, shimmering, spinning).

### Animation Rules
- **Scroll‑Triggered:** Elements should fade up (`y: 40, opacity: 0 → 1`) as they enter the viewport.
- **Stagger Effect:** Lists of items (cards, menu items) should appear sequentially with a `delay` of `0.05s` – `0.1s` between each.
- **Micro‑Interactions:**
  - Buttons: `scale(0.96)` on click, `scale(1.02)` on hover.
  - Cards: `translateY(-4px)` on hover with increased shadow.
  - Inputs: `border-color` and `box-shadow` transitions on focus.
- **Accessibility:** Always include `@media (prefers-reduced-motion: reduce)` to respect user accessibility settings.

---

## 4. 3D & Immersive Experiences (Three.js)

### When to Use Three.js
- Add depth to hero sections (floating geometric shapes, particle fields).
- Create interactive 3D "cards" that rotate on mouse move.
- Visualise data in 3D (e.g., network graphs, scatter plots).

### Technical Best Practices
Three.js** for plain HTML.
- **Performance:**
  - Limit polygon counts (use `BoxGeometry`, `SphereGeometry` with low segments).
  - Use `PointsMaterial` with `BufferGeometry` for particle fields.
  - Pause rendering when the scene is off‑screen using `useFrame` or `requestAnimationFrame` checks.
- **Lighting:** Use `AmbientLight` + `PointLight` or `DirectionalLight` for soft, realistic shadows.

---

## 5. Component Architecture & Layout

### Styling Framework
- Apply **Shadcn/ui** principles: high contrast, rounded corners (`rounded-xl` / `rounded-2xl`), and soft shadows (`shadow-2xl`).

### Layout Rules
- **Responsive:** Always build mobile‑first. Use CSS Grid (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`) for cards.
- **Progressive Disclosure:** Show summaries; hide details in accordions or hover‑activated tooltips to prevent overwhelming the user.
- **Spacing:** Use consistent spacing values (e.g., `gap: 16px`, `padding: 24px`).

---

## 7. The Micro‑Interaction Checklist

> **Apply these to every UI build by default:**

1. **Hover Lift:** Cards elevate (`transform: translateY(-4px)`) and increase shadow on hover.
2. **Smooth Scroll:** Enable `scroll-behavior: smooth` on the HTML element.
3. **Gradient Meshes:** Use subtle animated gradient backgrounds (via CSS `background-size: 200%` and `@keyframes` moving it).
4. **Loading Skeletons:** Show shimmering placeholders while data is loading.
5. **Focus Outlines:** Never remove `outline` without replacing it with a visible focus ring for keyboard accessibility.
6. **Button Feedback:** All buttons must have a `:active` state (scale down) and a `:disabled` state (opacity + cursor: not‑allowed).

const LIST_REVEAL_STAGGER_S = 0.035;
const LIST_REVEAL_DURATION_S = 0.24;
const LIST_REVEAL_SLIDE_PX = 8;

/** Paused — caller decides when to play via `playIfMotionAllowed`. */
export function buildListRowsRevealTimeline(rows: readonly HTMLElement[]): gsap.core.Timeline {
  return gsap.timeline({ paused: true }).fromTo(
    rows,
    { opacity: 0, y: LIST_REVEAL_SLIDE_PX },

  );
}

import { ChangeDetectionStrategy, Component, ElementRef, effect, inject, input } from '@angular/core';
import { ApprovalChainStep } from '@models/wwell-planning/wwell-planning.model';
import { playIfMotionAllowed } from '../../dynamic-form/gsap-motion.util';
import { WWELL_APPROVAL_STEP_STATUS_META } from '../wwell-approvals.config';
import { buildApprovalStepsRevealTimeline } from './wwell-approval-steps-reveal.animation';

export type WwellApprovalTimelineOrientation = 'horizontal' | 'vertical';

@Component({
  selector: 'app-wwell-approval-timeline',
  standalone: true,
  imports: [],
  templateUrl: './wwell-approval-timeline.component.html',
  styleUrl: './wwell-approval-timeline.component.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    '[class.approval-timeline--vertical]': "orientation() === 'vertical'",
  },
})
export class WwellApprovalTimelineComponent {
  private readonly elementRef = inject<ElementRef<HTMLElement>>(ElementRef);

  readonly reqNo = input<string | null>(null);
  readonly steps = input.required<readonly ApprovalChainStep[]>();
  /** 'horizontal' (default) preserves the existing WLDA/Land-Affairs approval-table look. */
  readonly orientation = input<WwellApprovalTimelineOrientation>('horizontal');

  protected readonly stepMeta = WWELL_APPROVAL_STEP_STATUS_META;

  constructor() {
    // Replays on first render and on every subsequent `steps()` change (e.g. switching the
    // selected IR in the detail sidebar, or expanding a fresh row in the approval table).
    effect(() => {
      this.steps();

      const items = Array.from(this.elementRef.nativeElement.querySelectorAll<HTMLElement>('.approval-timeline__item'));
      if (items.length) playIfMotionAllowed(buildApprovalStepsRevealTimeline(items));
    });
  }
}

import { IntegratedRequirement } from '@models/wwell-planning/wwell-planning.model';

export interface KvRow {
  readonly icon: string;
  readonly label: string;
  readonly value: string;
}

const EMPTY_VALUE = '—';

function fmtNum(value: number | null | undefined, unit?: string): string {
  if (value === null || value === undefined) return EMPTY_VALUE;
  return unit ? `${value} ${unit}` : `${value}`;
}

function fmtStr(value: string | null | undefined): string {
  return value ? value : EMPTY_VALUE;
}

  inject,
  signal,
} from '@angular/core';
import { FormsModule } from '@angular/forms';
import { ActivatedRoute, Router } from '@angular/router';
import { MatButtonModule } from '@angular/material/button';
import { MatIconModule } from '@angular/material/icon';
import { MatSnackBar } from '@angular/material/snack-bar';
import { IntegratedRequirement } from '@models/wwell-planning/wwell-planning.model';
import { buildDetailRevealTimeline } from '../shared/dynamic-form/detail-reveal.animation';
import { playIfMotionAllowed } from '../shared/dynamic-form/gsap-motion.util';
import { buildListRowsRevealTimeline } from '../shared/dynamic-form/list-reveal.animation';
import { WwellApprovalMiniChainComponent } from '../shared/wwell-approvals/wwell-approval-timeline/wwell-approval-mini-chain.component';
import { WwellPlanningStore } from '../store/wwell-planning.store';
import { WwellIrDetailComponent } from './wwell-ir-detail/wwell-ir-detail.component';
import { WWELL_IR_STATUS_META } from './wwell-ir.config';

const SNACKBAR_DURATION_MS = 3000;
const SKELETON_ROW_COUNT = 6;

@Component({
  selector: 'app-wwell-ir',
  standalone: true,
  imports: [FormsModule, MatButtonModule, MatIconModule, WwellIrDetailComponent, WwellApprovalMiniChainComponent],
  templateUrl: './wwell-ir.component.html',
  styleUrl: './wwell-ir.component.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class WwellIrComponent implements OnInit {
  protected readonly store = inject(WwellPlanningStore);
  private readonly router = inject(Router);
  private readonly route = inject(ActivatedRoute);
  private readonly snackBar = inject(MatSnackBar);

  protected readonly isLoading = this.store.integratedRequirementsLoading;
  protected readonly loadError = this.store.integratedRequirementsError;
  protected readonly isSubmittingForReview = this.store.updatingIntegratedRequirementStatus;

  protected readonly searchTerm = signal('');
  protected readonly selectedId = signal<string | null>(null);

  protected readonly rows = computed(() => {
    const term = this.searchTerm().trim().toLowerCase();
    const all = this.store.integratedRequirements();
    if (!term) return all;

    return all.filter(
      ir =>
        ir.code.toLowerCase().includes(term) ||
        ir.requestReference.wellName.toLowerCase().includes(term) ||
        (ir.requestReference.linkedRequestId ?? '').toLowerCase().includes(term) ||
        ir.requestReference.client.toLowerCase().includes(term),
    );
  });

  // Deliberately looks up the *unfiltered* store list (not `rows()`) so narrowing the search
  // never drops the current selection just because it fell outside the filtered results.
  protected readonly selectedIr = computed<IntegratedRequirement | null>(
    () => this.store.integratedRequirements().find(ir => ir.id === this.selectedId()) ?? null,
  );

  protected readonly statusMeta = WWELL_IR_STATUS_META;

  protected readonly skeletonRows = Array.from({ length: SKELETON_ROW_COUNT }, (_, index) => index);

  @ViewChild('detailHost') private readonly detailHost?: ElementRef<HTMLElement>;
  @ViewChild('listHost') private readonly listHost?: ElementRef<HTMLElement>;
  private previousSelectedId: string | null = null;

  constructor() {
    effect(() => {
      const message = this.store.createIntegratedRequirementError();
      if (message) {
        this.snackBar.open(message, 'Dismiss', { duration: SNACKBAR_DURATION_MS });
      }
    });

    effect(() => {
      const message = this.store.updateIntegratedRequirementStatusError();
      if (message) {
        this.snackBar.open(message, 'Dismiss', { duration: SNACKBAR_DURATION_MS });
      }
    });

    // Default to the first record once the list loads — mirrors the reference app, which
    // always has something selected in the detail pane rather than starting on an empty state.
    effect(() => {
      const all = this.store.integratedRequirements();
      if (all.length > 0 && this.selectedId() === null) {
        this.selectedId.set(all[0].id);
      }
    });

    effect(() => {
      const id = this.selectedId();
      if (id === null || id === this.previousSelectedId) return;

      const host = this.detailHost?.nativeElement;
      if (host) playIfMotionAllowed(buildDetailRevealTimeline(host));
      this.previousSelectedId = id;
    });

    // Re-plays whenever the visible rows actually change (initial load finishing, or the
    // search term narrowing/widening the result set) — not on every keystroke that leaves
    // the result set untouched, since `rows()` only changes reference when it does.
    effect(() => {
      const currentRows = this.rows();
      if (this.isLoading() || currentRows.length === 0) return;

      const host = this.listHost?.nativeElement;
      if (!host) return;

      const items = Array.from(host.querySelectorAll<HTMLElement>('.wwell-ir__row'));
      if (items.length) playIfMotionAllowed(buildListRowsRevealTimeline(items));
    });
  }

  ngOnInit(): void {
    this.store.loadIntegratedRequirements();
  }

  protected onSearchChange(term: string): void {
    this.searchTerm.set(term);
  }

  protected selectIr(id: string): void {
    this.selectedId.set(id);
  }

  protected openNewIrPage(): void {
    this.router.navigate(['new'], { relativeTo: this.route });
  }

  protected submitForReview(ir: IntegratedRequirement): void {
    this.store.submitIntegratedRequirementForReview(ir);
  }
}
