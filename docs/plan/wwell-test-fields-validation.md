# Well Test Fields Validations

**Classification:** Saudi Aramco: Company General Use

## Overview
This document specifies the field validation requirements (Required vs. Optional) for **PUMP** and **FLOW** well test types as communicated by the Hydrogeologist / Groundwater Division.
