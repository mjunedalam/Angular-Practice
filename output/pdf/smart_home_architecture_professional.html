Control Behavior

Local mode
Phone connects to Home Assistant on LAN. Commands execute through MQTT/relay modules even without internet.
Remote mode
Home Assistant Cloud, VPN, or secure reverse tunnel provides remote access. No direct port forwarding recommended.
Fallback mode
Physical switches/keypads remain connected. Essential lights must work without app/cloud.

Final Architecture Recommendation

Build the solution around a local Home Assistant gateway with MQTT, VLAN-separated networking, room-wise smart relay/dimmer panels, Zigbee sensors, and secure remote access. Keep all daily functions local: lights, fans, curtains, AC scenes, washroom exhaust, staircase lights, and exterior/garden scenes.

The strongest design is not a cloud-only smart home. It is a professionally wired local automation system with app, voice, scenes, and remote access layered on top.
