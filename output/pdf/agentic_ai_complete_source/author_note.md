# Corrections and edition updates

## Report a correction

Send corrections to [juned.alam.dev@gmail.com](mailto:juned.alam.dev@gmail.com). Use the subject **Agentic AI Engineering - correction**. Include the edition/version from the copyright page, the chapter and section heading, the printed page number, and a short description of the problem. A source, calculation or small reproducible example helps distinguish a technical error from a different design choice.

For code problems, include the lab name, Python version, installed dependency versions, command, expected result and observed result. Remove credentials, customer data and private records before sharing a reproduction. The examples use fictional records and local fixtures; a report should not require access to a reader's production system.

## How corrections are recorded

Reports are reviewed before they become confirmed errata. A confirmed entry records the affected edition, stable chapter/section, issue, correction and first corrected version. Page numbers can move after typesetting, so chapter and section identifiers remain the preferred reference. Unresolved questions remain distinguishable from verified errors.

When a corrected file is issued, its version and preparation date change and the companion changelog records the differences. Examples and their dependency notes are updated together when a correction changes executable behavior. This process does not imply a fixed response time or a guarantee that every future framework release will be supported.

## Working with the companion

The attached **Agentic_AI_Engineering_companion.zip** contains the example guides, dependency lists, tests and the chapter sources used by snippet tests. Keep the extracted `chapters/` and `examples/` folders together. Read `START_HERE.txt` before choosing a lab and consult its guide for the boundary between executed checks, simulated services and unexecuted integration work.

The diagrams, analogy limits, exercises and self-checks are part of this complete book. Technical references remain in the chapters and appendices so readers can inspect the mechanisms and version-specific claims behind the explanation.
